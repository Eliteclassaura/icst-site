### 2.5 Third-party dependencies

Google Fonts (runtime), Gmail SMTP via PHPMailer (app password), optional Cloudflare Turnstile, Cloudflare proxy (header trust), Hostinger LiteSpeed (`litespeed_finish_request`). Cited sources: Semrush, Ahrefs, Litmus.

### 2.6 Security concerns (ranked in `docs/risks.md`)

Critical: shared committed admin key protecting subscriber PII export and server diagnostics. High: `diagnose.php` in web root; `debug => true` in the config template; plaintext PII files. Medium: spoofable Origin-only CSRF defence, header-trusted rate-limit keying, default-on roadmap scan as an amplification/backscatter vector, token secret falling back to the SMTP password.

### 3.1 Capabilities (confirmed in source)

Ingestion of GSC exports (ZIP/CSV in 12 header languages, Generative-AI report, API `{rows:[{keys}]}` shape), Semrush Positions / Keyword Gap / Backlinks / Site Audit / Position Tracking, Screaming Frog & Sitebulb `internal_all.csv`, XLSX, gz, JSON/ndjson; GSC OAuth connector (implicit token flow, `webmasters.readonly`); BFS crawler via proxy (concurrency 4, depth ≤ 12, robots-aware, sitemap seeding) with rich per-page extraction; self-calibrating CTR curve; 12 data gates; eight finding families (striking distance, CTR gap, decay/risers, cannibalisation, keyword gaps, Semrush drops, reconcile); deduped ranked action queue; tf-idf greedy topic clustering with URL evidence and page-ownership verdicts; ~45-code technical audit incl. soft-404 and minhash near-duplicates; six-pillar health score (`SCORE_MODEL = 2`, weights 18/17/19/24/12/10) with grade bands 85/70/55/40; backlink profile (HHI anchor diversity, velocity, prospects); per-URL link profiles; internal-link planner; content briefs; media/schema/hreflang checks; SERP-feature suppression; AI Search module (8 eligibility checks, 9-component readiness score with weight renormalisation and withholding below 50 measured weight, page decision ladder, fan-out, manual AI Overview observations, citation packs); AI-readiness pillar (retrieval vs training crawlers, GEO signals, stuffing); markdown live editor scored with the same `readinessFor`; BYOK AI assist (Anthropic/OpenAI/Gemini/OpenAI-compatible) with redaction and spend cap; 22-module prompt pack with evidence injection; HTML/PDF report; 7-sheet XLSX; snapshots (`search-evidence-suite/snapshot` v1) with compare and 364-day YoY; project backups; Simple/Pro tiers; seeded sample data.

### 3.2 Data model

IndexedDB `seo-suite` v2: `projects`, `datasets`, `crawls`, `runs`, `drafts` (keyPath `id`, index `projectId`) and `meta` (`active`, `tier`, `aikey`, `aicfg`, `aispend`). AI-Overview observations live inside `project.cfg.observations`. `localStorage`: theme and licence marker only. Full record shapes in the discovery report §4.

### 3.3 Evidence model (to preserve exactly)

Four provenance classes — **observed** (GSC), **reported** (Semrush), **recorded** (crawl / hand-entered), **generated** (LLM, "deliberately the only one that no score, pillar, gate or action rank can read"). `null` is the consistent not-measured sentinel with weight renormalisation; unmeasured pillars leave the denominator; workbook writes empty cells. Only pillar weighting is versioned (`SCORE_MODEL`); technical checks, clustering and readiness rules are **not** versioned — a `RULES_VERSION` must be added on extraction. One vocabulary inconsistency: actions use `basis:'estimated'` while the report tag map knows `reported`.

### 3.4 Security concerns

Critical: private allowlist committed in `proxy.php`. High: BYOK provider keys persisted in plaintext IndexedDB; implicit OAuth grant; proxy unauthenticated by default. Medium: spoofable rate-limit key; CSV export without formula-injection hardening; `.htaccess` hardening commented out; project import trusts the file. XSS surface is well handled — every crawled/imported value passes `esc()`.

### 3.5 Migration implications

Roughly 90 % of analysis code is pure and portable to TypeScript as-is. Coupling points: `DOMParser` (`extractPage`, `htmlToDraft`), `DecompressionStream` readers, `fetch`, canvas, IndexedDB, and six hidden wall-clock reads. The characterization fixtures in `docs/baselines/ses-fixtures/` pin every engine output on the sample project; the 14 highest-drift calculations are listed in the discovery report §13.4.

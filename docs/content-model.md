# Content model

Implemented in `packages/agency-core/src/cms` (C3) and mounted by `apps/syed-ai/src/payload.config.ts`. Every collection carries the shared field groups where they apply: `seo` (title, description, canonical, noindex + required reason, OG image, primary topic, breadcrumb title, schema types, citations, reviewed/updated dates), `verification` (status · verifiedBy · verifiedAt · note — ADR-016), and for public content drafts + versions (`_status`, autosave, scheduled publish). All ids are UUIDs (ADR-018). Access rules are in `access/index.ts`; roles in `access/roles.ts`.

## Globals

`site-settings` (name, canonical origin, stats row with per-stat verification, hero status), `brand-settings`, `header` (primary/utility nav, palette entries, CTA), `footer`, `contact-legal` (offices, social profiles, privacy/terms/accessibility-statement pages), `seo-defaults` (title template, robots directives, robots.txt/llms.txt extras, organization/website/person entities), `integrations` (Turnstile on, analytics provider + consent flag, AI off by default with feature list and data-policy note, email provider, feature flags), `chat-config` (greetings, brief steps, roadmap steps, copy), `roadmap-config` (caps, AI agents, score weights, findings, plan phases), `email-templates` (five templates + signature), `spam-config` (phrases, domain lists, thresholds), `form-config` (shared select options so chat and form agree).

## Hooks

`auditAfterChange/Delete/Login` on every important collection and `auditGlobalAfterChange` on globals; `makeRevalidateAfterChange` (tags `collection:*`, `doc:*`, `path:*`; only when published state is involved; never fails a write); `makeSlugRedirectHook` (published slug change → `redirects` row).

## Editor

Lexical with a restricted feature set: paragraph, h2–h4, bold/italic/underline, internal links to content collections, lists, blockquote, horizontal rule. No raw HTML, no arbitrary embeds (master prompt §Payload content model).

## Not yet

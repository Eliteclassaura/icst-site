# Factory prerequisites — what must land before H2O, with acceptance criteria

All findings below were verified against the checkout at HEAD `88f5469` on 2026-09-05. Items P1–P5 are needed for any WordPress migration; P6–P8 are the OGCS-specific additions. Each is a separate PR, guarded by the existing parity gate on syed.ai (20 routes, 0 blocking) and the threat-model suite.

## Ordering and risk

P2 first (it is a pure addition and everything else validates against it), then P6 (unlocks Lane B for existing clients immediately, independent of H2O), then P1 + P3 + P4 (all touch `agency-core`; ship together as "C6-migration-readiness" with one migration), then P5, then P7. P8 only when OGCS has an endpoint to receive it.

Every `agency-core` change is additive. The syed.ai parity gate and the 84 threat-model tests are the regression guard; no existing behaviour is removed.

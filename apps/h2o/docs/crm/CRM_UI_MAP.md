# CRM_UI_MAP — H2O / ICS CRM-1

The private UI is the existing Payload admin at `/admin`. CRM-1 adds no frontend framework. All
collections sit in the **CRM** nav group, and nothing is shown to users without the right role (viewer
gets 404 on CRM lists).
